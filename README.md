# 💼 Chukka Tulasi Reddy's Portfolio Website

This is a **personal portfolio website** built using **HTML, CSS, and JavaScript**. It showcases my skills, projects, and contact information. The site is simple, responsive, and beginner-friendly — a great reflection of my current web development capabilities.

---

## 📌 Features

- ✅ Section-based layout: About, Skills, Projects, Contact
- 📷 Profile picture and brief introduction
- 🛠️ Skill list using ordered lists
- 📁 Project showcase with table layout
- 📬 Contact form with radio buttons, checkboxes, and input fields
- 🔝 Fixed "TOP" button to scroll easily
- 🎨 Custom-styled with hover effects and clean visuals

---

## 🧪 Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and layout
- **JavaScript (Basic)** – Interaction like fixed "Top" button
